## Features

- [Go](https://go.dev/) - Programming language for the web, CLI, desktop and more.
- [Bootstrap](https://getbootstrap.com/) - Frontend toolkit with utilities for HTML & CSS.

## Environment Setup

The project requires Go v1.26+. Please ensure a minimum of Go v1.26 is installed.

Clone the project

```bash
  git clone https://github.com/peterkitonga/gowebapp
```

Go to the project directory

```bash
  cd gowebapp
```

## Run Locally

Start the development server

```bash
  go run ./cmd/web
```
